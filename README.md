# Fitness App

A simple fitness app made with Flutter for practice. It shows how to use animations and custom painters.

![FitnessApp gif]( https://media.giphy.com/media/HMWY4GWqEs8RB3I4dg/giphy.gif )

## Features

- Login screen
- Home page with a chart of your activity
- Activity page with a workout list
- Nutrition page with a calories circle and meal cards
- Meals screen with meal categories

## Requirements

- Flutter 3.47 or newer (Dart 3.13)

## How to run

```bash
flutter pub get
flutter run
```
